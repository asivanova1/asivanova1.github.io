📁 Мои проекты

1. 🏗️ «Здесь нам жить!» — благоустройство аллеи (2025)

Проект по созданию 3D-модели аллеи в программе SketchUp. В рамках работы было проведено анкетирование 72 жителей, выявлены недостатки территории (освещение, дорожки, лавочки). На основе анализа создана модель с новыми объектами: лавочки, урны, фонари, деревья, киоск, расширенная парковка, пешеходный переход. Рассчитана полная смета проекта — 18 175 000 рублей. Проект защищён на школьной конференции.

2. 🌐 Этот сайт

Персональный сайт-портфолио, созданный с использованием генератора статических сайтов Hugo. Сайт размещён на GitHub Pages, имеет розовую тёмную тему, адаптивный дизайн, поддержку категорий и постов. Включает информацию обо мне, моих навыках, проектах, достижениях, научных ресурсах.

4. 🐧 Введение в Linux (внешний курс на Stepik)

Статус: ✅ Успешно завершён (сертификат получен)

Ссылка на сертификат: 📜 Открыть сертификат (Stepik)

📘 Раздел 1. Основы работы в Linux
На этом этапе я изучила:
• Установку виртуальной машины и базовую настройку системы.
• Навигацию по файловой системе: команды cd, ls, pwd, понимание структуры каталогов.
• Права доступа к файлам и папкам: chmod, chown, чтение прав (rwx).
• Управление пакетами в Ubuntu: apt, установка и удаление программ.
• Работу с командной строкой: терминал, консоль, базовые команды.
• Перенаправление потоков ввода/вывода: >, >>, 2>, | (конвейеры).
• Архивацию и сжатие файлов: tar, gzip, zip, unzip.
• Поиск файлов и загрузку данных: find, wget, curl.

💻 Раздел 2. Удалённая работа, процессы и биоинформатика
В этом разделе я научилась:
• Подключаться к удалённым серверам через SSH и копировать файлы (scp).
• Работать с FTP-клиентом Filezilla для передачи данных.
• Управлять процессами в Linux: jobs, fg, bg, kill, top, htop, сигналы (SIGKILL, SIGTERM).
• Использовать tmux для сохранения сессии на сервере (чтобы задачи не прерывались при отключении от SSH).
• Работать с биоинформатическими программами:
    - FastQC — оценка качества данных секвенирования (fastq, fasta, bam, sam).
    - ClustalW — множественное выравнивание нуклеотидных и аминокислотных последовательностей.
    - bowtie2 — выравнивание ридов на референсный геном (построение индекса и само выравнивание, многопоточный режим).

✍️ Раздел 3. Vim, bash-скрипты, sed, gnuplot
Здесь я освоила:
• Работу в редакторе vim: нормальный, командный и визуальный режимы; навигацию по словам (w, W, e, E, b, B); редактирование, замену текста (:%s/old/new/g), выделение, копирование и вставку.
• Написание bash-скриптов:
    - переменные ($var), аргументы ($1, $2, $#, $@);
    - условные операторы (if-elif-else, case);
    - циклы (for, while);
    - функции и арифметические операции (let, (( )));
    - обработку кодов возврата ($?).
• Обработку текста с помощью sed: замена по регулярным выражениям, опции -E, -n, -i.
• Построение графиков в gnuplot: настройка осей (set xtics), подписей, легенды (set key), анимации (pause, reread), опция -persist.
