1. 🏗️ "Let's live here!" — alley improvement (2025)

Project to create a 3D model of an alley in SketchUp. As part of the work, a survey of 72 residents was conducted, shortcomings of the territory (lighting, paths, benches) were identified. Based on the analysis, a model was created with new objects: benches, urns, lamps, trees, a kiosk, an extended parking lot, a pedestrian crossing. The total budget of the project is 18,175,000 rubles. The project was defended at a school conference.

4. 🐧 Introduction to Linux (external course on Stepik)

Status: ✅ Successfully completed (certificate received)

Link to certificate: 📜 Open certificate (Stepik)

📘 Section 1. Linux Basics
At this stage I studied:
• Installing a virtual machine and basic system setup.
• Navigation through the file system: cd, ls, pwd commands, understanding the directory structure.
• File and folder permissions: chmod, chown, reading permissions (rwx).
• Package management in Ubuntu: apt, installing and removing programs.
• Working with the command line: terminal, console, basic commands.
• I/O redirection: >, >>, 2>, | (pipelines).
• Archiving and compressing files: tar, gzip, zip, unzip.
• Searching for files and downloading data: find, wget, curl.

💻 Section 2. Remote work, processes and bioinformatics
In this section I learned:
• Connecting to remote servers via SSH and copying files (scp).
• Working with FTP client Filezilla for data transfer.
• Process management in Linux: jobs, fg, bg, kill, top, htop, signals (SIGKILL, SIGTERM).
• Using tmux to save a session on the server (so that tasks are not interrupted when disconnecting from SSH).
• Working with bioinformatics programs:
    - FastQC — quality assessment of sequencing data (fastq, fasta, bam, sam).
    - ClustalW — multiple alignment of nucleotide and amino acid sequences.
    - bowtie2 — alignment of reads to the reference genome (index building and alignment itself, multi-threaded mode).

✍️ Section 3. Vim, bash scripts, sed, gnuplot
Here I mastered:
• Working in the vim editor: normal, command and visual modes; word navigation (w, W, e, E, b, B); editing, text replacement (:%s/old/new/g), selection, copying and pasting.
• Writing bash scripts:
    - variables ($var), arguments ($1, $2, $#, $@);
    - conditional operators (if-elif-else, case);
    - loops (for, while);
    - functions and arithmetic operations (let, (( )));
    - handling return codes ($?).
• Text processing with sed: replacement using regular expressions, options -E, -n, -i.
• Plotting in gnuplot: setting axes (set xtics), labels, legend (set key), animation (pause, reread), -persist option.
