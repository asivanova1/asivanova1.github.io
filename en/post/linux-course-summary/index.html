🐧 Results of the Linux Introduction course on Stepik

May 17, 2026

During this time, we have come a long way. From scratch we figured out what Linux is (using Fedora Sway as an example), learned how to work in the command line, mastered process management, I/O redirection, archiving, searching files and text (grep, find).

We understood how SSH keys work, copying files to a server (scp, Filezilla), working with tmux, installing and running bioinformatics programs — FastQC, Clustal, bowtie2, including multi-threaded mode.

We mastered vim and Emacs editors, learned how to write bash scripts: from simple calculators to functions, loops and command line argument processing. We figured out the Git version control system, the Gitflow branching model, semantic versioning and signing commits via GPG.

We learned how to work with Markdown, design reports and presentations, compile them using Quarto and Pandoc. We got acquainted with Midnight Commander, the pass password manager and configuration management via chezmoi.

As a result, we were able to install Linux on a virtual machine, set up a development environment, write dozens of scripts, design reports for all laboratory works and upload them to a GitHub repository.

The main thing is that now we are not afraid of the terminal, we understand how the system works, and we can solve practical problems.

🔥 It was a tough but very useful experience.
