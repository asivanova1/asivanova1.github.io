My week: bash and emacs

26 April 2026

This week I completed lab work on the course "Computer Architecture and Operating Systems".

Lab No. 11 — emacs editor
I got acquainted with the powerful text editor emacs. I learned how to create, edit and save files, use keyboard shortcuts for navigation and editing, work with buffers and windows, perform search and replace. Emacs is a complex but very flexible tool. Keyboard shortcuts are scary at first, but you get used to them.

Lab No. 12 — bash programming
I learned the basics of writing scripts in the bash shell. I developed 4 scripts:

  • backup_self.sh — creates a backup of itself
  • print_args.sh — prints all passed arguments
  • myls.sh — analogue of the ls command (without using ls itself)
  • count_files.sh — counts files with a given extension

Both lab works were defended, reports completed. My skills in working with the command line and text editors have become noticeably better.
