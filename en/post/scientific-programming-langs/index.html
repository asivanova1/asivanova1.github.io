Scientific programming languages

13 May 2026

Python is the most popular language for scientific computing. Libraries: NumPy, SciPy, Matplotlib, Pandas. Used in machine learning, data analysis, physics, biology.

MATLAB / GNU Octave — classic engineering calculations. Working with matrices, modeling systems. Used in signal processing, robotics, control.

R — the king of statistics and data visualization. A huge number of packages for analysis. Used in biostatistics, economics, sociology.

Julia — a young and fast language created specifically for scientific computing. Speed like C, simplicity like Python. Used in high-performance calculations.

C++ / Fortran — for the most demanding tasks in terms of speed. Fortran is still actively used in physics and meteorology.

Currently I am learning Python for data analysis, and also writing bash scripts for task automation in Linux. In the future I want to try Julia — they say it is the future of scientific computing.
