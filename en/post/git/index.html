Git: version control system

11 April 2026

Git is a distributed version control system that allows you to track changes in files and work on a project as a team. It was created by Linus Torvalds for the development of the Linux kernel.

Basic commands:

  • git init — creates a new repository
  • git add — adds files to tracking
  • git commit -m "message" — saves changes
  • git push — sends changes to a remote repository
  • git pull — downloads changes from a remote repository
  • git clone — copies a remote repository

Git also supports branching (git branch, git merge), which allows you to work on different versions of a project in parallel. GitHub is the most popular platform for hosting Git repositories, which also provides free static site hosting through GitHub Pages.
