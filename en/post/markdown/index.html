Markdown — lightweight markup language

11 April 2026

Markdown is a simple markup language that allows you to format text without using a mouse. It was created by John Gruber in 2004.

Basic syntax:

  • # Heading 1
  • ## Heading 2
  • **bold text**
  • *italic*
  • - list item
  • [link](url)

Markdown is used everywhere: on GitHub (README, issues, comments), in Hugo (writing posts), on Telegram, in Jupyter Notebooks, and many other places. Its main advantage is simplicity and readability even in source form.
