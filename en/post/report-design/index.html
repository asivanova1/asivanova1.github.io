Report design: best practices

26 April 2026

When I was doing my school project "Let's live here!", I learned how important it is to format a report correctly.

Rules for a good report:

  • Structure: title page, table of contents, introduction (relevance, goal, objectives), theoretical part, practical part, conclusion (findings), references, appendices.
  • Formatting: single font (Times New Roman, 14 pt), 1.5 line spacing, justified alignment, page numbering, references in square brackets [1].

My advice: start formatting your report right away, not on the last day. A well-formatted report is respect for yourself and for the reviewer.
