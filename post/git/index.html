Git: система контроля версий

11 апреля 2026

Git — это распределённая система контроля версий, которая позволяет отслеживать изменения в файлах и работать над проектом в команде. Она была создана Линусом Торвальдсом для разработки ядра Linux.

Основные команды:

  • git init — создаёт новый репозиторий
  • git add — добавляет файлы в отслеживание
  • git commit -m "message" — сохраняет изменения
  • git push — отправляет изменения на удалённый репозиторий
  • git pull — загружает изменения с удалённого репозитория
  • git clone — копирует удалённый репозиторий

Git также поддерживает ветвление (git branch, git merge), что позволяет работать над разными версиями проекта параллельно. GitHub — самая популярная платформа для хостинга Git-репозиториев, которая также предоставляет возможность бесплатного хостинга статических сайтов через GitHub Pages.
